# Rapid impact assessment - UNDP + LRC

Interactive web map of population, displacement, conflict zones and damage to public institutions in South Lebanon and Nabatiyeh.

**Live map:** https://abdallah-al-assaad.github.io/Rapid-Impact-Assessment-UNDP-LRC/

## Sources
- South & Nabatiyeh Governorate population and IDP sheets (21 Sep 2026)
- LRC Preliminary Assessment (Jun–Jul 2026), incl. damage to public institutions
- GeoAI plugin for QGIS (Mask R-CNN) on Esri World Imagery – building detection around Khiam and around each damaged public institution
- Lebanon cadastres: UNICEF Lebanon GIS

Built in QGIS and exported to GeoJSON. Preliminary data for coordination only. The boundaries and names shown do not imply official endorsement or acceptance by the United Nations.
